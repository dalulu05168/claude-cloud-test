# 课堂写作
完整晚课、关键多人互动或按范文写作时，先读项目根目录的 [编剧样本索引](../../../reference/writing-samples/index.md)。选与本场问题最接近的样本，沿用其中的课堂推进方法。人物、用词和承接内容由当期素材决定。用户点名的范文优先。日常短句润色直接按指定范围写。

遇到完整场景时，让角色发言各自推动内容。成员可按所见提问、互相解释、质疑或改口。围绕自然发生的疑问设计承接。真实成员画像使用有依据的细节。教学模拟使用用户给的编号或示例身份并清楚标识。人物身份、持仓、下单和盈利记录使用已核实资料。

遇到带编号的成员发言或跨场承接时，按 [成员口吻与出场](../../../reference/member-cast.md) 核对导演给出的旧版身份和课堂前情。典型发言标签是两位编号加性别。同名人员按编号区分。新稿候选以 [统一配置](../../../reference/scene-rules.json) 为准。原稿摘录中的历史编号保留其原貌。选择和本场有关的未答问题或学习进度，以本场内容推进对话。

先生讲清楚现象、证据和判断方法。主课内容与成长任务可以在同一个来回完成。成长任务带出后继续本课当前的讲解。预留给下一课的原因和流程按用户给的深度处理。涉及机构资金时，区分可见的价量行为和需要额外证据的身份、目的及交易计划。

资讯助理开闭场简短自然。先生负责授课、发布练习。Gabriela 的收答或积分提示在用户当次安排需要时再写。按用户给的时段、语气、发言头和段落范围输出。用户只要求一段就直接给该段。

新稿走 [基础版出稿规则](../../../reference/agent-workflow.md)。周一三五下午默认由助理和成员发言，先生按教学安排出场。助理新闻、活动、行情卡和教师稿按各自模块。

写早午晚场次时，按导演交给你的已确认交接挑需要承接的一两项。可以接前一场成员的具体问题、告知尚待收的答案，或者把与当晚课程有关的问题留给先生。确认已发的资讯可一句带过，某个数字更新时写清楚新时点。前一场的草稿不能当作群里已经发生的对话。

写群聊时查 [中文发言口吻](../../../reference/whatsapp-voice.md)。所有角色用中文，体现罗马尼亚人聊天时直接简短、就事论事的节奏。每位成员通常一条短句，复杂条件可用两句。通常不带表情，语境需要时放一个。各角色禁用中文套话、中式表达风格和股票黑话。
