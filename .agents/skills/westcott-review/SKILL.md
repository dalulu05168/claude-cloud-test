# Westcott 独立审稿

审稿只返回审查结果，不保存状态、不采用稿件、不发送消息。先按照用户要求和导演给出的范围审查，不能把个人偏好当作阻塞问题。涉及写法、成长任务或人物互动时，查 [编剧样本索引](../../../reference/writing-samples/index.md)，只读与当前问题相关的样本。

## 必查项目

| 类别 | 通过条件 | 阻塞情形 |
| --- | --- | --- |
| 范围 | 正文覆盖用户要求的场次、条数和停点 | 擅自扩大、遗漏核心范围或越过等待节点 |
| 连续性 | 从已确认末句接入，保留待答问题和任务边界 | 复述已发内容、跳过待答项或提前回答后续课题 |
| 教学推进 | 课程知识和成长任务在互动中同步推进 | 只讲结论、成员只作装饰或人物成长没有依据 |
| 人物互动 | 只使用确认过的成员身份、口吻、近况和学习进度 | 新造身份、把模拟反馈写成真实反馈、重复已解决的基础问题而没有推进 |
| 事实边界 | 现实事实有核查状态；假设、教学模拟和真实记录分开 | 编造最新数字、来源、公告、持仓、盈利或实际群内行为 |
| 格式 | 角色标记、新闻结构、教学格式、条数和配图符合参考规范 | 角色混用、段数错误、新闻缺图或配图与事件证据不对应 |
| 口吻 | 中文、简洁、自然，符合罗马尼亚 WhatsApp 投资群节奏 | 中式群聊套话、炒作口号、股票黑话或模板化台词 |
| 后续边界 | 未解问题和下一课承接清楚 | 把留给下一课的内容提前解决，或没有可执行的下一步 |

## 细则

承接检查要区分最终稿、备课草稿、教学模拟和未来安排。误用其他课程的进度，把待解问题当成已学，或让人物提前知道尚未出现的信息，均为阻塞问题。若短段落被扩成整晚、修改了用户要求保留的内容，或用内部分析替代正文，也应阻断。

课堂推进不能只在结尾提一句成长任务；应指出具体讲解、成员问题或先生答复如何把主课知识与成长任务连接起来。角色互动应围绕当前话题，不能让成员一直重复老师观点。能从正文指出具体来回，才算完成成长任务。

稿件带成员编号时，按导演提供的人员表核对编号、性别、称呼、候选范围、讨论倾向和成长阶段。历史原文可以保留其编号，但新稿不得把模拟成员或交易写成真实记录。已答问题继续向前，新话题仍允许问；若重复基础问题没有推进，提出最小修复。

按 [基础版出稿规则](../../../reference/agent-workflow.md) 核对当日开场、角色权限、播报类型和节点。财经新闻检查标题、事实段、影响及关注段、官方图及其来源。先生发言按晚间或本场获准的教学模块判断，检查证据边界及解释。成员使用本地群聊表达，避免重复、单人连环问答和未经确认的真实交易发言。

按 [新闻与场次规则](../../../reference/news-broadcast-policy.md) 审核核查员给出的原始发布时间和实际排稿顺序。普通新闻必须为罗马尼亚当地当天，只有上午允许美股上一交易日指标与美国前夜重大新闻。对照白天已发新闻检查跨场倒序。按 [统一配置](../../../reference/scene-rules.json) 查完整场发言总条数，按 [运营记录](../../../reference/operations.md) 和当日确认材料核对推票、活动、课程与停点。

## 结果格式

第一行只返回 `通过` 或 `需修改`。若需修改，按严重程度列出阻塞项；每项引用正文中的短原句，说明影响，并给出最小修复方向。无法凭当前材料判断时写“待核”，不要猜测。可选润色放在阻塞项之后，不能阻止交付。

复检时只检查上一轮指出的问题和改动引发的新问题。若独立审稿代理不可用，总导演必须按本 Skill 和 `reference/instruction-execution.md` 自检，并在稿外如实说明“未启动独立审稿”。独立审稿结果不代表用户已采用稿件。
