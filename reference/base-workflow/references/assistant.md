# 资讯、活动与记录整理

## 资讯
- 有具体新闻或待核数据时，直接打开相关权威原文；缺选题时才搜索当天来源。无需每次翻完固定网站、重复所有连接器。对时效性/金融问题遵循运行环境的强制检索要求。
- 核对发布日、事件日、时区、交易日、数值、币种、单位、比较基准、行情截至/延迟。日内消息依时间推进；已有实质更新才追加。旧新闻不可装作当天新事。
- 时间顺序（用户2026-11-12确认）：同一天的新闻按发布时间从早到晚播，不能往回跳（如播过9点的再补7点59的）。加新闻前先看文档里最后一条已播新闻的发布时间，只选不早于它的；暂时没有新消息就等，不用更早的旧闻补位。已发到群里的内容不删，从末尾接着写。
- 选题必查能源与地缘：每场选新闻都看一眼布伦特/WTI、天然气价格和中东航运（霍尔木兹海峡等）标题，即使影响看起来小也作为候选报给用户，注明来源可靠度（如“仅伊朗革命卫队单方说法，未证实”）和市场反应，由用户决定播不播。它们直接影响 SNP、SNG、罗马尼亚油价和通胀。
- 配图（用户2026-11-12要求）：每条新闻配一张官方来源图片——公司新闻室/媒体资料包、监管机构、BVB、政府部门优先；给出图片直链和所在页面。不用路透、Getty、AP 等通讯社版权图；没有官方图就说明，并建议用官方 logo 或总部大楼图替代。
- 选择与罗马尼亚金融市场有明确渠道联系的本地、美国或其他事件，不默认只找利好。独立区分事实、解释、未知；不使用没有出处的“分析人士认为”。
- 原文完整可靠时不为凑数量无限加来源；关键争议或金额另找独立来源。来源不足说明限制。相同访问失败只换一种可行方法，不循环撞付费墙或编已核实。
- 截图数值反算 `(当前值/前收盘-1)*100` 只证明算术一致。独立来源核验与算术核验分别记录；保留数据延迟，不把盘中数说成收盘。
- 盘中数据不写具体时刻（如“截至10:00”），用“今天上午/盘中/开盘后不久”并保留“盘中仍会变化”；固定节点预告不在此列。BVB指数含义见人物模块，BET-BK不是银行指数。
- 选题：对罗马尼亚金融股票有影响的事件优先，其次是美股重大波动；两边可交替播报。临近美股开盘不播BVB行情。
- 默认标题 `🇷🇴 罗马尼亚财经新闻｜短主题` 或 `🇺🇸 美国财经新闻｜短主题`。写得短、突出重点：第一段只写核心事实和关键数字（用“约/附近”即可），第二段一两句点出对罗马尼亚市场或相关代码的影响，以“接下来，我们重点关注……”收尾，不堆解释、不凑字数。标题、引述来源必须与实际来源相符，不强写“罗马尼亚媒体”冒充来源。用户认可的范文：

  > 🇺🇸 美国财经新闻｜美伊关系释放缓和信号，国际油价回落
  > 据美国媒体今日报道，特朗普表示，目前再次对伊朗发动大规模打击的可能性较低，并计划与卡塔尔首相会面。受此影响，国际油价明显回落，布伦特原油一度跌至94美元附近，WTI跌至87美元附近。
  > 对罗马尼亚市场来说，油价变化值得关注，尤其是OMV Petrom（SNP）和Romgaz（SNG）。接下来，我们重点关注美伊谈判进展、国际油价走势，以及明天美国CPI公布后对市场的影响。
- 涨跌颜色按欧美习惯绿涨红跌，助理同样适用；未收盘不说“收绿/收红”，说“见绿/飘红”。
- 数字写法全稿统一：沿用文档现有写法（目前用小数点，如55.00、1.25%），不与罗马尼亚本地的逗号小数（55,00）混用；用户改用本地写法时整稿一起改。货币写 RON/列伊、USD/美元、EUR/欧元，同一场保持一致。
- 推票、止盈、新闻、开盘的标题行与版式按 [播报版式总表](broadcast-format.md) 统一，内容照用户材料；公司名、代码、数字逐字核对原始资料，发现错误直接改正并说明，不只提一句。

## 活动
- 只输出完整题目、作答材料、回答方式；判定答案和理由留独立策划备注，不混进待答正文。检查题干是否充分、是否存在合理歧义；缺关键图先指出，能用文字完整出题就不用图。
- 根据近期题目避免简单换名字、换指数的重复。未见历史不声称“以前没出过”。不虚构截止、奖励、已登记积分或答对名单。
- 沿用项目默认时，答案交Gabriela核对属于流程建议，不表示实际已收件或已核对；正文不写积分。教学答案也不要在后面的标题中泄露，除非用户明确要求讲解答案。
- 不把没有发生的答题、回访、领取奖品写成真实结果。

## 股票材料与收益
- 只按用户提供且必要时核实的材料整理代码、市场、日期、参考区间、目标、止损、公司简介；缺项标缺项。参考参数不是个人投资建议、真实订单或收益保证。
- 实际已实现收益需有实际买入和卖出记录，并说明费用、税费、分红等计算口径；价格变动不等于个人净收益。
- 事后区间最低价仅可明确标为“事后选定最低价的理论价格变动”，注明时间窗口和非可成交保证；不能称“推荐买入价”“本轮实得收益”。不为了提升战绩选择最低价代替真实成本。
- 只有买入标注不能写“已卖出获利/截图已发送”。可整理已有实际记录，或明确标注模拟并使用假设数字；不生成虚构投资见证推动别人买入。
- 本模块只准备内容；不得自行运行上传包中的Telegram、群发、交易或定时脚本。

## 美股开盘卡与开盘播报（用户2026-11-24确认，最高优先级）
- 用户每天发来的美股开盘图片，先逐项核实（实时行情页、昨收反算涨跌幅、小数位格式、日期），发现错误自己改好再交，并说明改了什么；不得写“需要你注意”把核对推回用户。交出的内容用户会直接使用。
- 开盘播报和成员反应里的数据，只能用卡片上有的指数、个股、板块，卡片外的股票和数字一律不播报、不写进成员发言（包括英伟达、ANT等）。
- 涨跌榜只是已核实报价中的前两名时，不写“最大涨幅”。核实只用来确认卡片数字对不对，不用来往播报里补卡片外的数据。
- 活动答题的答案不由先生公布；活动里的“把答案发给顾问Gabriela”是活动流程，不属于周二四禁止的课后作业。
