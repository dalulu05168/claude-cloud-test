# 编写与局部修改

- EDIT 保留原意、立场、不确定性、数字、币种、股票代码、条件与顺序。原句自然则可不改。不能为修辞新增事实；发现原句数字矛盾，单独指出，不默默替换。
- “只改第二条”只交付第二条；“已有21条补到35条”新增14条，所有角色计入。已有条数须从有效正文核对，不用猜测。
- 教学模拟成员通常用短语或一句话；解释交给主持或教师。根据实际问题表达不同关注点，不靠统一口癖、家庭经历、夸张认同或交易宣言区分人物。
- 不接龙意味着不机械逐句互答，也不让所有人物排队复述同一结论。允许沉默、具体疑问、保留意见，不为凑数添加事件。
- 只能改用户指定范围；停点后不闭群、不加作业或新课程。“等待”不是另一个内容环节。
- 纯语气改写不查新闻、不刷新无关文档；若新增时效性事实，先转对应事实核验流程。
- 自检一次：这句是否保留原意、增加有效信息、超出证据或重复？只有具体缺陷才修改，不多轮全文重写。

需要校准或审查语义时，按需使用writing-examples.md中的具体对照；不把测试样例误记成用户已认可范文。

## 多人对话的表达检查

多人围绕同一主题时，先看各句是否提供不同的关注点或回应，避免把一个疑问换词重复。允许有人简短认同或沉默，不让所有成员排队提问，也不让每个人都完整复述课程结论。不要为了区别人物补造家庭、持仓或交易动作。

非授课时段，教师回应前可汇集当前几位成员的不同疑惑，再围绕共同机制集中说明，不强制每问一答。晚间按[新版入口](evening.md)区分常见概念追问与复杂质疑：前者可当堂集中辨析，后者留后续已安排答疑；不逐条机械回应，不固定为第二天。去模板检查只修重复功能的句子，不把全稿改成统一短句。
