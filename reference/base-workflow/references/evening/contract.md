# 共同执行约定｜v1.2.0

## 体系与范围
本晚间模块来自《WESTCOTT晚间课程独立Skill v1.2.0细化完善稿》，服务于ELLERY WESTCOTT第二阶段晚间课程。五项职责归并原九个内部模块；现按用户本次要求覆盖2.2.9的晚间规则，上午、下午、周日复盘规则保留。
五项职责在同一个技能内按需读取，由同一助手执行，不要求多代理。总入口为本包SKILL.md，不依赖另外安装5个技能。

## 不变逻辑
- 周一、三、五技术课，周二、四理念课；理念课对应最近一至两节技术课。周二、四不留作业，不改名为课后观察、打卡或提交任务。
- 晚间20:00主课；继承原项目Europe/Bucharest时区，用户或有效课程状态明确另设时采用该设置，不按执行主机时区推断。
- 四个学习阶段依次为形态基础、基础反转、持续整理与延续、综合判断；这些是课程内部阶段，不等同于其他项目阶段。根据理解、执行及风险评估推进，不因时间、课次数量或盈利自动升级。
- 教学模拟图与真实市场案例分离；优先有依据的持仓案例，其次当日市场，再次一般市场现象，无匹配就不用。不能把推荐或待确认买入当持仓事实。
- 事实→相关可能性→证据不足与待验证条件→课程概念。不得仅凭K线识别机构身份、意图或一级市场传导，不能为了植入概念补造市场归因。
- 理念递进：专业分析→市场结构→一级/二级市场概念→机构视角→机构方法→我们的方法与标准。信任源于可验证的方法，不以身份或盈利承诺替代教学。
- 禁止虚构资质、能力和成员背书；机构视角不表示机构总是正确。“我们”只能描述有依据的方法和身份。
- 新编成员对话必须标明【教学模拟｜非真实成员发言或交易记录】；不得将模拟反应、买卖或收益包装为实际反馈。
- 正式课程课件DOCX、宋体、嵌入图片；教学PNG为3840×2160、16:9、绿涨红跌、正式Logo左上。原稿中的“建议”参数仍为建议，不提升为强制要求。
- 不授权发群、外部发布、交易、自动排程或修改其他技能。技能不会自动获得行情源、Logo、字体、真实持仓或持久记忆。

## 交接信息
按当前任务需要传递以下信息，不强制每次输出整张表：
- 课程ID、版本、状态、日期、星期、20:00及课程时区；
- 当前学习阶段、前课已讲内容与证据、本课类型、主题、目标、核心误区、下课承接；
- 已讲理念、本次理念推进点、暂不展开内容；
- 案例是否采用、资料来源、观察截止时点、周期及已知限制；
- 图号→文件→章节→判断点的对应关系；
- 缺失输入、验收结果、未解决问题与下一步。
状态使用计划、草稿、已定稿、已授课。仅生成文件不能升级为已授课；没有课堂记录不能写成员已理解。缺失数据不填成事实。

## 使用原稿
references中的分章规则保留原文；其中“下一步做”“可安装草案”“四周排课表”等表述是成果方向，不是当前执行授权。优先本次用户范围；冲突须指出具体条款，不悄悄合并。
真实金融事实需核原文和时间点。无检索能力时不编造实时行情，可继续模拟教学部分。输出只完成用户要求的范围，不把规则编辑自动扩大为整套课件。
