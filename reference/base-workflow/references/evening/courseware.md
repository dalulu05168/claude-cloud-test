# Westcott 晚间课件与标准形态图

先读[共同执行约定](contract.md)，制作时读[图表与课件全部规格](part-05.md)。

## 执行
1. 根据本次课程方案确定教学点、图组与输出范围；正式Logo默认采用../../assets/westcott-logo-original.png，不再向用户重复索取。若用户仅要配图方案，交付图号表；要求成品时完成PNG嵌入DOCX，不能只给制作建议。
2. 分离标准模拟图与实际案例图。模拟数据只服务形态教学，并注明“教学模拟示意，非真实行情”；不得据此虚构股票或时间。
3. 为形态安排形成前、形成中、关键位、确认、常见误判、失效等4—6张建议图组；按知识重点选择，单图只讲一个重点。同一图组沿用基础走势，不能提前展示未来结果。
4. 用可控绘图工具生成K线、量柱与标注，保证OHLC关系有效、量非负。不要用生成式绘图随机拼出不可核验的K线或乱码文字。选择环境中可用的绘图与DOCX工具，不假定已有某个私有插件或脚本。
5. 图为原生3840×2160无损PNG，16:9。上涨绿色、下跌红色，以收盘对开盘判定；中性K线与文字涨跌幅说明口径。左上Logo不变形不遮挡，正式品牌色。
6. 原稿的建议参数：Logo宽384—499px，默认约442px；上左边距96px；标题72—88px、标注44—56px、辅助文字建议≥36px。使用前核对Logo比例及实际版面，原稿建议配色见规格文件。
7. DOCX正文宋体，图片嵌入对应位置，图号与讲稿一致。需明确配置中文字体，不用字体名称存在代替渲染检查；缺宋体时说明并请求素材或保留待验状态，未经说明不称合规成品。
8. 使用可用文档工具将DOCX渲染成页面并检查实际显示效果，修复溢出、缺字、图片变形或标注难辨。无渲染工具时检查文件内部结构并明确“页面视觉待核”，不能全部判通过。

## 交付
交付实际DOCX、所用PNG、图号对应表及本次无法完成项；只有方案时明确方案状态。缺Logo不擅自重绘或冒充正式品牌，可先完成其他图文，标记品牌验收待核。无外部数据时继续模拟图，不伪造市场案例。

示例图号：图01形成前、图02结构初现、图03关键位、图04确认、图05误判、图06失效；是否采用全部图号由实际课题决定。
