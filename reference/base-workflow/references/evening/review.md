# Westcott 晚间课程验收

先读[共同执行约定](contract.md)，再读[验收标准](part-08.md)及[开发检查边界](part-09.md)。检查图片或DOCX时读[图表规格](part-05.md)，并取得实际文件及本次采用的建议参数，不能只凭制作说明判通过。

## 执行
1. 确认待审成果、用户范围与课程状态。没有实际授课或采用证据，不把候选稿视为已采用历史。
2. 课程：检查阶段、先后、技术理念对应、前后承接。四阶段不等于四周；没有理解证据的推进记待核。
3. 表达：区分事实/解释/条件，查市场数据时点与来源，查是否把机构身份、意图或一级市场传导写成定论。仅添加“可能”却无相关线索也需修正。
4. 理念：检查阶段适配与教学价值，删除无依据的身份能力陈述、收益保证或突然营销；不能用虚构成员好评证明专业。
5. 互动：检查模拟标识、发言功能差异、合理误解与承接，不要求所有人都发言；模拟反馈不计入真实学习结果。
6. 课件：打开实际PNG核像素、绿涨红跌、K线与量柱、图号和Logo。读取DOCX内部格式并在可用环境渲染检查字体、布局和清晰度。无文件或无法渲染，相关项写待核。
7. 周二四检查显式及变相课后任务，包括要求明日交图、提交观察、打卡。课堂即时辨析可保留。
8. 只修有证据的问题及受影响的关联处，不借审校重排全部逻辑。修复后针对改动复核，保留尚缺材料的事项。

## 交付
“项目—通过/待核/不通过—章节/图号/文件证据—必要修改”。随后给用户指定范围的修订稿及未解决项。结构检查通过不等于事实、自然度、图文、平台行为全部通过；没有Claude实际回执，不称已安装或目标平台实测通过。
