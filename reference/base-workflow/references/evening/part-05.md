# 第五部分｜图表制作与课件标准

## 5.1 课件格式
- **统一 DOCX**
- 全文主字体：**宋体**
- 不使用 PPT 作为最终主交付
- 图片插入 DOCX 对应位置
- 课件与图号严格对应

---

### 5.1 补充执行细节｜DOCX编排建议
- 在原有章节结构内，依次呈现课程信息、目标与承接、问题引导、案例说明（如有）、形态讲解、例子辨析、理念总结、互动设计和下节承接；不适用的内容注明原因。
- 正文建议小四号宋体、1.5倍行距；一级标题建议三号加粗，二级标题建议四号加粗。定稿选定后保持全套一致。
- 图片按原比例嵌入正文，采用稳定的嵌入式排版；图号、图题及简短说明紧邻图片。解释较多时放在正文，不把长段文字塞进图内。
- 完整图因页面宽度缩小后仍须可读；必要时另加局部细节图，不用拉宽原图改变比例。
- 此处DOCX要求针对后续正式课程课件；规则说明稿的文本完善不等于已经制作或验收课件。

## 5.2 教学图统一标准
### 尺寸
- 3840 × 2160
- 16:9
- PNG
- 原生高清
- 不允许模糊拉伸

### 画质要求
- 线条清晰
- K 线实体、影线、量柱可辨认
- 文字清晰
- 缩略图状态下也保持较好可读性

---

## 5.3 左上角 Logo 统一规则
### 位置
- 左上角固定位置

### 边距
- 与左边、上边保留统一安全边距

### 比例
- 保持原始比例，不拉伸
- 建议占整张图宽度约 **10%—13%**
- 不得过大影响图表主体

### 背景
- 优先透明底
- 不得用难看的色块遮挡图表内容

### 遮挡规则
Logo 不得遮挡：
- 图标题
- K 线主体
- 坐标轴
- 成交量
- 关键标注
- 颈线 / 边界线 / 关键位

### 颜色
- 使用正式品牌颜色
- 不得随意换色
- 不得因美观随意改版

---

### 5.3 补充执行细节｜Logo参数建议值
- 以3840×2160画布为基准，Logo宽度范围为384—499像素，系列默认可取约442像素；高度按原始纵横比计算，不单独强设。
- 左侧与顶部安全边距建议统一为96像素。根据Logo实际高度预留品牌区域，再安排标题和绘图区；标题或K线不得侵入该区域。
- 透明底素材须保留透明通道；低清素材不能靠放大冒充高清。无正式素材时标记“待提供正式Logo”，不自行重绘或用文字冒充。
- Logo过高或与内容冲突时，先调整标题和图表区域，再在既定宽度范围内调整Logo；不得裁切、变形或覆盖关键内容。
- 参数在一组课程中固定；确需变更时按同一模板统一更新，避免逐图漂移。

## 5.4 图表颜色统一规则
按照你长期要求：

- **上涨：绿色**
- **下跌：红色**

建议补充统一为：

- 成交量：对应浅绿色 / 浅红色
- 关键位 / 颈线 / 边界线：橙色虚线
- 辅助线 / 均线：蓝色或灰蓝色
- 高亮区域：浅米色 / 浅灰底
- 普通文字：黑色 / 深灰色

---

### 5.4 补充执行细节｜系列配色建议
| 元素 | 建议色值 | 使用说明 |
|---|---|---|
| 上涨K线 | #168A55 | 收盘价高于开盘价 |
| 下跌K线 | #D64545 | 收盘价低于开盘价 |
| 对应量柱 | #A6D8BE / #EAB1B1 | 跟随对应K线方向 |
| 关键位置 | #E58B2A | 使用虚线，并配文字标注 |
| 辅助线 | #577A9E | 与主要形态线保持区分 |
| 高亮区域 | #F6F1E7 / #F1F3F5 | 使用浅底，不遮蔽K线 |
| 正文标注 | #252525 | 保证与背景对比清晰 |

- 上表是原配色要求的参数化建议，不替换Logo正式品牌色。
- 平开平收的中性K线可用灰色，并在图例说明；“绿涨红跌”的K线判定口径固定为收盘对开盘，案例文字中的涨跌幅另行注明比较基准。

## 5.5 图中文字规则
- 与课程用语一致
- 简洁、专业、统一
- 一张图只讲一个核心重点
- 图标题、课件标题、先生口头表述保持一致
- 不要在图中堆满长段文字

---

### 5.5 补充执行细节｜文字可读性
- 在3840×2160图中，主标题建议72—88像素，主要标注建议44—56像素，坐标与辅助说明建议不小于36像素；最终以DOCX实际显示效果复核。
- 标注使用引线或留白区，与实体、影线和量柱错开。颜色不能成为唯一提示，确认、待确认和失效均需配文字或线型区别。
- 统一词表，例如同一课内“颈线”“确认”“失效”保持一致；首次使用缩写时在正文解释。

## 5.6 图形内容规则
- 统一使用标准化模拟形态图
- 不使用真实股票走势直接代替教学图
- 每张图解释一个阶段或一个判断点
- 每种形态可使用多张图表现“形成前 / 形成中 / 确认后 / 失效后”

---

## 5.7 推荐的教学图组结构
以一种形态为例，建议一套 4—6 张：

1. 形成前
2. 结构初步出现
3. 关键位置出现
4. 确认触发
5. 常见误判
6. 失效或反例

这样比一张“完成后的标准图”更适合教学。

---

---

### 5.7 补充执行细节｜图组连续性与命名
- 同一形态图组尽量复用相同基础走势；后续图只增加新出现的K线、条件或分支，避免成员误以为每一步都换了一个案例。
- 每根模拟K线须满足高点不低于开、收盘价，低点不高于开、收盘价；量柱非负，标注与所指K线一致。
- 形成中图不提前显示未来确认结果。失败图明确指出哪一条件未成立或何处失效，不将其画成“先保证成功，再突然失败”。
- 建议命名：课程编号_形态名称_图序_阶段.png；DOCX图号、脚本引用和图片文件建立对应表。
- PNG采用无损输出。交付前核实际像素尺寸，不能只检查文件名或导出设置。
