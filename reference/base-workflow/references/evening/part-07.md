# 第七部分｜Skill 输出要求

每次运行本 Skill，至少应输出：

## 1）课程方案
- 今晚课程主题
- 所属阶段
- 技术 / 理念类型
- 教学目标
- 与前后课程承接

## 2）授课逻辑
- 先生怎么开场
- 如何回顾白天市场
- 如何切入案例
- 如何进入标准教学图
- 如何植入理念
- 如何总结与承接

## 3）成员互动设计
- 哪几类成员发言
- 每人发言功能是什么
- 谁提误区
- 谁追问
- 谁承接

## 4）图表课件要求
- 需要哪些形态图
- 图号与作用
- Logo 规则
- DOCX 规则

## 5）验收清单
- 是否跳级
- 是否自然
- 是否呼应
- 是否有过度宣传
- 是否把可能性说成事实

---

### 输出细节补充
- 课程方案须标出本次版本与状态，写清输入资料中哪些已核对、哪些仍待补充。
- 图表清单逐项列图号、对应章节、核心判断点、图内标注和制作状态；尚未出图时只能称为图表方案。
- 如本次仅要求完善规则，交付规则稿即可；实际课程运行时再按本部分生成课程方案、脚本及课件，不自动扩展任务。
- 缺少市场数据时可继续完成模拟教学部分；缺少正式Logo时可完成版式方案，但不声称品牌成品已通过验收。
