# Westcott 晚间课程总控

先读[共同执行约定](contract.md)。规划时读[课程路线](part-03.md)，需要定义完整输出时读[输出要求](part-07.md)；模块归并见[模块职责](part-06.md)，体系边界见[总体定位](part-01.md)，总纲见[课程目标](part-10.md)。不默认读取完整来源稿。

## 执行
1. 判断本次范围：排课、单课规划、整课制作、局部编辑或恢复进度。用户只要求排课时，不自动写整堂对话和生成图片。
2. 从用户实际提供的前课和检查点确定课程位置；恢复时使用[进度模板与规则](progress.md)。未知进度先标出；可先给候选方案，但不认定过去已经讲过。
3. 保留原四阶段及形态先后关系。四周是可用排课窗口，不是必须四周讲完全部形态。不能将四阶段直接等同四周。
4. 按星期分配技术/理念课，定义一个核心知识点、判断能力、误区，说明前后课承接及本次理念推进点。周二四不留作业。
5. 完整任务按需要读取本包五项职责并完成课件图表、先生授课、成员互动、质量审校；局部任务只使用有关职责，一个助手依次执行。
6. 输出用户需要的课程方案及实际完成的成果。资料不足的字段写待补，不以“需进一步规划”代替能够完成的内容。
7. 用户要求保存/交接时，导出填写后的课程检查点；仅写到会话临时空间时提醒用户保存，下次随新聊天提供。不声称安装后自动记住。

## 五项职责与交接
| 内部职责名称 | 负责原模块 | 交接成果 |
|---|---|---|
| westcott-evening-control | 总控、排课、理念节奏与状态 | 课程方案、学习阶段、推进点、检查点 |
| westcott-evening-courseware | 课件规划、标准形态图 | DOCX、PNG、图号表及制作状态 |
| westcott-evening-teacher | 现实案例、先生授课、理念展开 | 案例依据、九步授课稿、确认/失效条件 |
| westcott-evening-interaction | 成员互动 | 标明模拟性质的问答、功能与插入点 |
| westcott-evening-review | 验收 | 逐项证据、最小修改及未解决项 |

以上名称表示合并包的内部职责；按晚间入口读取control、courseware、teacher、interaction、review.md，不依赖外部安装，也不声称已经自动调用。

## 例子
输入：“周四，上一节讲W底，安排今晚理念课。”
输出应围绕“反弹为何不等于确认见底”，承接W底的确认误区，给框架与下课方向；不跳讲头肩顶，不留课后任务，不补造当日行情。
