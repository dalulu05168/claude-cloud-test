# 第十部分｜一句话总纲

这套晚间课程独立 Skill 的根本目标不是：

> “每天讲一个形态。”

而是：

> **通过技术课 + 理念课 + 标准教学图 + 市场案例 + 自然互动，在一段时间内逐步提升成员的理解、判断、信心与方向感，同时循序渐进地建立对先生、对方法、对团队视角的信任。**


## 1.《Westcott_Evening_Pattern_Course_v1.2.0_SKILL正文草案》
就是按 Claude Skill 的口吻，直接写成可安装/可拆分的 Skill 文本结构。

## 2.《晚间课程四周详细排课表》
把每周一三五技术课、周二四理念课，逐堂写清楚：
- 课程名称
- 课程目标
- 配图需求
- 理念钩子
- 可植入的重点
