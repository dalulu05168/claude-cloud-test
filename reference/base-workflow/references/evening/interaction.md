# Westcott 教学模拟互动

先读[共同执行约定](contract.md)。成员类型、自然度与衔接读[授课及互动规则](part-04.md)的4.2、4.6、4.7；涉及机构表述时读[身份与表达边界](part-02.md)的2.3—2.5。

## 执行
1. 按用户实际提供的讲稿、前情和角色资料设计互动；角色名称、人数或发言条数没有要求时，按教学需要安排，不默认65人、固定编号或全部出场。
2. 找到本课真实难点，选择疑惑、误解、追问、连接、反思或承接功能。并非每课集齐；一条发言围绕一个主要问题，不能多人换词复述。
3. 新编多角色对话首行保留【教学模拟｜非真实成员发言或交易记录】。只做互动设计表时，表头也注明教学模拟预案，不称实际聊天记录。
4. 成员以短句、具体困惑为主，解释交给先生；允许有人沉默、保留意见或说尚未明白。不要所有成员都像分析师，也不固定同几人机械轮换。
5. 误解必须合理且能被本课纠正，不故意编极端错误。追问紧接具体图号或判断条件，先生回应讲依据，不能只靠权威压下质疑。
6. 不虚构个人家庭、持仓、买卖、盈亏、加入经历或机构资质。模拟案例不变成团队战绩或真实成员已理解的证明。
7. 互动协助教学与自然过渡，不组织集体赞扬、替机构作证或诱导跟单。机构有关问题仍遵循事实与可能性边界。

## 成员口吻（2.3.1）
成员怎么说话按[人物约束](../members.md)的“罗马尼亚成员的表达习惯”和“晚间课程里的成员”两节，本模块只管互动怎么设计。写成员插话前先读那两节，不点编号也要读。
- 第2步的六种功能之外，质疑、反问、不服都可以出现，比例不必低于配合教学的发言。
- 原稿中“成员联想到自己持仓”写成不带个人事实的问法或留【持仓】占位；原稿示例里的“抄底”“拉起来”不搬进成员台词。
- 成员称呼先生用名字或姓氏加“先生”，不说“老师”；先生和助理称群里的人为“成员”。
- 发言长短、表情多少以真实群聊为准，不统一成一个样子。

## 交付
需要设计时给“插入位置—发言功能—模拟发言—先生回应要点”；需要正文时输出有模拟标识的完整片段。不把幕后功能表塞进最终授课对话。局部修改只改指定部分，不另加收尾和作业。

示例：成员问“碰到颈线就算确认了吗？”；先生结合本课图号说明触及与确认的差别及仍需观察的条件。不得用“先生说是就肯定会涨”收尾。
