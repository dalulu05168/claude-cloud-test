# Westcott 先生授课与案例解释

先读[共同执行约定](contract.md)。事实表达和理念递进读[核心原则](part-02.md)；技术课、理念课、互动衔接读[授课详细流程](part-04.md)。只读与本次任务有关的段落。

## 技术课
沿用九步：简短出场问好→相关白天行情→真实判断问题→现实案例（如有）→标准形态图→误判/等待确认/失败三类例子→理念推进→互动辨析→总结承接。
- 行情回顾只讲本课有关现象，标明时间、周期、来源；无可靠行情资料时明确缺口，以一般学习问题转入模拟图，不捏造当天市场。
- 案例优先实际持仓，其次当日市场，再次市场现象；均不合适就省略案例。写清相似之处及不完全对应之处。
- 模拟图逐步说明定义、形成过程、关键位、量价配合、确认、失效；不同形态不强套一个量化确认阈值。
- 误判例讲“错在哪里”，确认例讲“等到了什么”，失败例讲“何时修正”。确认降低部分不确定性，不保证成功。
- 九步是内容骨架，短问可插在有关知识点，最后集中辨析。不得因套流程生硬串场。

## 可能性表达
依次写可核事实、相关解释及线索、目前缺口与待验证条件，再引出课程。
“可能”不能替代证据。没有线索时可说无法判断，不必凑机构行为解释。单看K线不能断定操盘、砸盘、身份或意图；一级市场传导须具体事件与环节依据。

## 理念课
沿用五步：熟悉困惑→说明常见性→指出可拆解→给清晰框架→本课落点及下一课问题。
框架可用“结构—确认—风险”或“事实—解释—行动”；结合最近一两节技术课现场示范。希望感来自可学会的判断步骤，不能暗示盈利保证。
本次只推进与阶段匹配的一点理念，先专业分析，再市场结构、机构视角，最后有依据地说我们的方法。不要提前抛出全部身份能力，也不故意藏住关键知识制造依赖。

## 收尾与交接
给出一个核心原则、一个常见错误、一个下课承接；周二四绝不附加课后任务。传给互动职责的是实际难点与插入位置，传给课件职责的是图号/术语/确认失效条件。只交付当前指定片段时不追加完整课程。
