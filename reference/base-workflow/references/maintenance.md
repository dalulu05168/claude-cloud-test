# 规则维护与场次复盘

## 规则维护（用户 2026-11-25 确认）

本 Agent 是持续成长的，不沿用单一固定规则。新增或修改规则时，同一次操作内必须删除或改写被取代的旧规则：在 CLAUDE.md、`reference/` 与 `reference/base-workflow/` 内搜索同一主题的旧表述，改成最新版本，不并存两套说法，也不留“旧默认仅供参考”这类尾巴。没有冲突时只增不删。每次规则变动后同步更新 `manifest.json` 哈希，并在交付里说明删掉了哪些旧规则。

## 场次结束复盘（用户 2026-11-25 确认）

完整版由用户记录在谷歌文档。每个时间段（上午、下午、晚间）结束后，用户说“某场结束了”或同义表达，我读当天页签该场的最终内容，只读不写：运行 `review_draft.py`（带实际日期与 `--scope`）核对格式、口吻、条数和统一播报版式；有对应草稿时运行 `adoption_diff.py` 对比；再读 `recent_adopted.py` 摘要核对节点与前两天是否一致。交付一份简短复盘：用户改动了什么、我的不足、建议并入的规则。规则按「规则维护」并入，同时删除被取代的旧规则；并入前先给用户看，不擅自改。复盘不修改谷歌文档，不保存停点。
