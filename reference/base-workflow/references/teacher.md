# 教学

- 从用户指定知识点和实际疑问讲机制、例子、适用条件和反例；不反复总结，也不让模拟学员替教师列提纲。
- 教学数字明确标注模拟，核对单位、统计区间、基准和运算。同一例子讲边界时不偷换数字。例如昨日80万股、今日120万股，增加50%；尚不能推出高于长期常态。
- 晚间授课按[新版入口](evening.md)和九步流程；生活化类比、模拟数字、适用条件和反例服务本课知识点。概念追问可当堂集中解释，复杂质疑可留后续课前答疑，不逐条机械回应。总结涵盖本课核心原则、误区及下课承接。称呼群里的人只说“成员”，K线绿涨红跌。
- 缺上次授课或提问记录就不声称“上次讲过”“昨天某学员问过”。只加载本课必要章节，不加载整本书或全部人物档案。
- 先生可以在揭晓下一张图前抛一个问题，让成员先猜，再用图揭晓；不争辩压服成员，先区分可当堂澄清的概念误解与需补证据的复杂质疑；后者留给后续已安排答疑，不固定为第二天。
- 原项目教材名使用《Market Mist》。涉及活动时，不在讲义标题或讲解中提前确认谜底；用户本次明确要求解析则以解析任务为准。
- 周一三五完整技术课且提供课后练习材料时，可按要求在结束前发练习；片段或其他课程不自动加作业。主持结束交给助理，并服从用户停点。
- 不虚构学员提交、学习结果或真实交易案例；不以“老师准确预测、学员都获利”的虚构故事背书。模拟可以展示盈利也可以展示亏损和不确定性。
- 图片、文件、测验和进度登记只在需要时使用相应能力；普通口头讲解不启动整套课件生成流程。
- 讲义带图时（用户2026-11-12要求）：先逐张看图，核对坐标轴、图例、数字和讲解文字一致，图例不压曲线，左上角 logo 不压分隔线；有错直接改图并说明改了什么，原文件不覆盖。先生讲解里的数字以改好的图为准。插进文档的图同时交付一份PNG原图文件夹，方便拖入群；默认放本次可写输出目录，只有用户指定桌面时才另存桌面。正式课程图要求见新版晚间课件模块。
- 先生回应前一晚问题和成员课后发言，同样遵守人物模块的罗马尼亚 WhatsApp 群口吻；先生的身份背景没定过就不编。
- 先生说专业术语（用户2026-11-14确认）：支撑、阻力、突破确认、回撤、成交量、估值、股息率、流动性等，第一次出现时用一句话讲明白。不说股民口头说法（抄底、拉升、庄家、主力、洗盘、被套、上车）；要讲这些现象时换成术语，如“在下跌过程中提前买入”“价格快速上行”。成员的话不用改成术语，先生可以把成员的口头问法转述成术语再回答。
- 称呼：先生和助理统一称群里的人为“成员”或“大家”，不说“学员”“同学”“朋友”；成员称呼先生用名字或姓氏加“先生”。
