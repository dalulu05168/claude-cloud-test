# 播报版式总表

助理的所有播报用同一种标题行：`图标 类别｜具体内容`。标题单独一行，用全角「｜」，不在标题前后另加文字。日期统一写成「2026 年 11 月 25 日」（数字与年月日之间有空格，月日不补零）。价格区间的连接符统一用短横「–」，不混用「‑」「-」。

| 内容 | 标题行 |
| --- | --- |
| 前夜收盘回顾 | `🇺🇸 美股｜昨晚收盘回顾`（周一写「上周五收盘回顾」，休市后写「前一交易日收盘回顾」） |
| 财经新闻 | `🇷🇴 罗马尼亚财经新闻｜事件标题` 或 `🇺🇸 美国财经新闻｜事件标题` |
| 开盘播报 | `🇷🇴 罗马尼亚股市开盘｜当天具体情况` 或 `🇺🇸 美股开盘｜当天具体情况`，不用「开盘播报」这种固定标题 |
| 推票 | `📊 精选股票｜代码`，随后 `🏢 公司简介｜公司名（代码）` |
| 止盈 | `📈 阶段止盈｜代码` |

止盈提醒的版式与推票卡片对齐：标题行后空一行，接「发布日期：…」，再接一组 `📌` 字段，字段行之间不空行，依次为股票名称（代码）、推荐买入价格、阶段止盈参考价、本轮参考收益；最后一行 `💡 温馨提醒：` 说明已卖出的成员把交易截图发给顾问Gabriela。具体数字照用户材料，不自行补算。旧稿里的「GIS 阶段止盈提醒」「参考价格」「买入价格」「推荐价格」等写法不再使用。
