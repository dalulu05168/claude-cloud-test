# 平台适配与首次运行

命令示例使用 Windows 的 `python`；Linux/macOS 可改用 `python3`，Windows 也可用 `py -3`。先运行对应的 `--version` 确认 Python 3.9+；若打开 Microsoft Store 或返回异常退出码，请换用实际解释器。含空格的脚本或数据路径需加双引号。

## 能力检查

先依据本轮实际工具判断：是否可读技能文件、可执行Python、可读取指定文档/网络、可持久保存文件。不能凭技能安装成功推断其他权限已开通。不要要求或输出API密钥。

核心检查与记忆脚本需要Python 3.9+，只使用标准库，无需安装依赖或联网。可选教学图脚本render_evening_chart.py另需Pillow和可用中文字体；DOCX制作按环境能力选择文档工具并渲染验收。新版本首次使用运行一次`python /实际技能目录/scripts/preflight.py --self-test`。LOCAL_READY只验证本地文件和脚本，不表示Claude已触发、外部工具已授权或记忆已持久保存。普通短任务不重复运行全套测试。

先从实际加载的SKILL.md位置确定根目录，使用脚本绝对路径，或先切换到该目录；不要硬编码作者电脑、ChatGPT工作目录、盘符或猜测Claude安装路径。输出文件放本轮可写工作目录。整个目录迁移后本地引用保持相对关系。

## 旧版迁移

本技能取代用户提供的 `Westcott-5Skill-增强版-完整.zip` 中的 `westcott-control`、`westcott-director`、`westcott-writer`、`westcott-members`、`westcott-assistant`、`westcott-teacher` 写作入口；旧包还包含 `westcott-independent-writer` 的 `independent-writing` 入口及五分工来源副本，迁移时也需核对是否启用。不要将该入口的独立进程要求与新版的本地分流混用。评审另提及的 `westcott-scene-writing`、`westcott-role-craft` 若在其他环境存在，也由本技能替代；它们未出现在本次旧包中。安装时核对实际已启用列表；若旧版仍在，应由用户确认后在所属平台停用，避免自动选择旧规则。description 的替代声明不会自动停用任何已安装技能；未查到也不代表所有平台均不存在。保留旧版文件作为备份，不把旧版与新版同时用于同一任务。

## Claude网页端

将本包的单个`westcott-efficient-workflow`目录打包上传到Claude的自定义Skills入口并启用，开启代码执行。普通附件上传不等于安装。首次请求明确“使用Westcott精简执行”，核对实际读取/运行结果。

若网页端不能跨会话保留脚本写出的状态文件，完成已授权记忆更新后导出JSON，并向用户提供可下载文件。新会话只加载最新导出及必要正文。不能从本地保存成功推导平台原生记忆已更新。

## Claude Code

完整目录放入该环境支持的个人或项目技能目录；使用实际加载位置执行。记忆文件放用户项目的可持久目录，项目代码和发布权限继续遵循该项目约束。不要自动复制生产数据或提交用户未授权的外部更改。

## Claude API

由调用应用上传并附加技能、提供代码执行工具。技能容器中的脚本无需网络或动态安装依赖；实时资料由应用的获授权工具提供，不能假定脚本能联网。

持久记忆由调用应用保存导出文件，并在下一容器恢复；不能只依赖复用容器ID。API凭证、存储授权和服务端实现不包含在本包中。

## 无工具与跨平台降级

- 能读取文字但不能运行代码：完成不依赖代码的编辑；标明检查为人工检查，不能报程序PASS。
- 没有目标文档：使用用户完整提供的片段，或指出具体缺少哪段，不尝试其他账户冒充读取。
- 没有新闻/行情工具：不新增未核实实时事实；可做不依赖实时数据的教学或改写。
- 没有保存工具：给出待保存变更，不能声称已记住。规则、数据、权限分别迁移；账号授权不能装进ZIP。

## 版本与重复入口检查

运行 `python scripts/bundle_doctor.py` 读取当前脚本所在包的版本并核对manifest.json列出的文件SHA-256。校验和只检查意外修改，不是数字签名。只在安装/升级后检查，不在每次短改写时运行。

可加 `--scan-root /实际技能安装目录` 查找该目录内重叠的Westcott入口；只报告文件，不能据此认定插件已启用，不自动修改配置。若用多个安装位置，分别指定检查。保留旧包，实际停用须按用户授权在所属平台完成。

同机新聊天恢复读[跨聊天协议](session.md)；目标平台安装及行为验收读[验收集](acceptance.md)。恢复依赖相同系统账户、数据目录和文件访问权限。新版不自动导入旧手册或旧进度。
