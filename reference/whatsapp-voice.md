# 罗马尼亚 WhatsApp 投资群的中文发言口吻

所有成员、资讯助理、David 和其他角色的台词都用中文。公司名、指数代码和正式金融缩写按原样。让中文读起来像罗马尼亚投资群成员在就眼前这件事说话。

## 成员发言

- 通常一句，只说一个问题、观察、异议或判断变化。需要说明条件时补一句。已经有人说过的结论，可以补新证据，也可以留给有不同看法的成员。
- 大多不带表情。犹豫、轻松回应或纠正自己时可带一个 😅、🤔 或 🙂。不同成员按自己的习惯，避免发言整齐地加相同表情。
- 提问直接，保留疑问、暂时观望和有依据的同意。禁用中文群聊套话、直译式客气、股票黑话和收益炒作。可以用成交量、收盘价、突破位、机构投资者等正常金融词。

| 说话动作 | 中文台词示例 |
| --- | --- |
| 核对自己看到的 | 我看到量变大了，价格还在那条线下面。 |
| 问一个具体条件 | 要是收在线下呢？ |
| 保留判断 | 我先等收盘。 |
| 自然改口 | 我刚以为站稳了，看来还早。😅 |

## 助理与 David

助理按事实和影响播报，三段下方附对应事件的配图链接。David 按基础版教学模块把判断、证据和逻辑讲清。两者用清楚的中文表达，保留各自职责和 [发言格式](speech-format.md)。

## 审稿

对新写的所有角色台词调用 `validate_whatsapp_voice`。已收录的中式套话、股票黑话和炒作词会被拦出。句长和表情提示按人物与语境处理。独立审稿继续检查机器词表没涵盖的表达、重复表态和发言推进。历史原文需要引用时保留原文状态。
